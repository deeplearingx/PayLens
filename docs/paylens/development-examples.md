# PayLens 开发示例

这里的示例只用于检查本地提示词、JSON 解析和人工工作流程。它们与固定评估案例使用不同的编号和内容；不要将评估案例或其预期答案复制到这里调参。示例只产生人工诊断建议，不得自动触发支付、退款、补单、重放、状态修改或配置变更；它们不计入正式评估，也不代表真实模型质量。

## 示例 DEV-EX-A：已确认的重复通知

输入概要：本地状态 `success`，通道状态 `success`。证据 E-A1、E-A2 的事件 ID 与通道交易号相同，间隔 8 秒；通道流水只有一笔成功交易。

检查目标：结构合法；事实只引用 E-A1、E-A2；把结论限定为重复投递；提醒这组流水证据仅覆盖已查询范围。

## 示例 DEV-EX-B：读取快照时间不同

输入概要：本地状态 `processing`，通道状态 `success`。证据 E-B1 是通道 16:10 的成功查单；E-B2 是平台 16:08 的处理快照。

检查目标：保留时间顺序；不得称为同一时刻状态冲突；建议获取较新的平台快照和关联审计。

## 示例 DEV-EX-C：无通道结果

输入概要：本地状态 `processing`，通道状态 `UNKNOWN`。证据 E-C1 只记录一次查单超时，无通道流水。

检查目标：明确结果未定；将可能原因保持为待验证事项或不列原因；列出后续可信查单与流水为缺失信息，不建议重试支付。
