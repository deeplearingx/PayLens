# PayLens AI 改进评测（2026-10-03）

这里的样例由仓库中的冻结脚本生成，标签和评分要点只留在评测文件，不进入事件分析提示词。开发集先用于阈值选择；随后只在独立保留集读取最终指标。样例均为人工编写的合成现象，不能代表生产支付事件分布。

## 本地检索

- [分析开发集](analysis-dev-v2.json)：20 例；[分析保留集](analysis-holdout-v2.json)：40 例，常规异常、信息不足、证据冲突、无匹配各 10 例。
- 使用 `python scripts/evaluate-hybrid-retrieval.py` 复算 [检索结果](retrieval-offline-report.json)。Java 生产路径采用相同的 BGE CLS 池化、L2 归一化、查询前缀、两路前五名和等权 RRF（常数 60）。阈值在 0.50—0.98、步长 0.02 中从开发集选出 0.54。
- 保留集混合检索 Recall@3 **90.0%**、MRR **0.672**；关键词基线分别为 **0%**、**0**；无匹配组误检率两路均为 **0%**。检索指标达标，但下述云端评阅发现额外知识引用拉低支持度，因此演示默认仍为关键词模式，混合检索保留实验开关。该召回增益只适用于这组特意包含同义改写的合成案例。无匹配组还混入与支付无关的报表/文件类描述，0% 误检不能外推到线上。

## 相似事件建议

- [建议开发集](merge-dev-v1.json)与[建议保留集](merge-holdout-v1.json)各含 100 个查询事件，每个查询 10 个候选；其中 20 个查询没有相关候选。描述模板按集合区分。跨商户或通道边界的候选即使文本相同也必须被拒绝。
- `python scripts/evaluate-merge-suggestions.py` 使用本地 BGE 和硬边界复算 [建议结果](merge-offline-report.json)。Precision@3 按全部查询的三个推荐位计算，避免通过少展示候选虚增精度；开发集在搜索范围内**没有合格阈值**。为排查失败原因，报告另列实验阈值 0.80：保留集 Precision@3 **38.0%**、Recall@3 **47.5%**；若仅计算已经展示的建议，其精度为 **79.2%**。跨规则边界建议 **0**。建议接口保持 `UNCALIBRATED`，演示开关关闭。语义自动合并始终关闭。

## 云端配对评测

运行 `scripts/Invoke-PayLensImprovementEvaluation.ps1` 会从本地 `.env` 读取现有兼容接口配置。运行器创建持久调用账本，在发请求前标记 `STARTED`；被中断、失败和限流的请求均计入 120 次硬上限。40 个保留案例以随机顺序各跑一次关键词和混合检索，共 80 次初始请求；每组最多 20 次结构修复。修复仅用于 JSON 语法、缺字段或字段类型问题，调用同一生产修复上下文。可用 `-MaxCalls 0` 预览并创建冻结账本，随后用同一 `-RunDirectory` 续跑。

`scripts/summarize-ai-improvement-evaluation.py` 从账本和原始响应生成 `paired-results.json` 与不含条件映射的 `blind-review.json`。AI 评阅应按预先冻结的“答案覆盖、无据推断、引用支持、建议风险”四项评分，并标明“AI 辅助评分，未经独立人工验证”；不能从评分直接宣称诊断准确率提升。独立 PostgreSQL 和登录后的工作台流程需要另行验证。

本轮已完成 [80 次调用账本](cloud-paired-v3/ledger.json)、[配对指标](cloud-paired-v3/paired-results.json)与 [AI 辅助评分](cloud-paired-v3/ai-assisted-scoring-report.json)。关键词与混合各 40 次初始请求均完整通过结构和引用范围校验；没有触发修复，故云端调用共 80/120，**不能据此推断修复成功率**。关键词组 / 混合组总 Token 分别为 170,936 / 194,716，首次请求耗时中位数分别为 34.2 / 35.5 秒。AI 辅助评分的引用支持均分为 2.00/2 与 1.70/2，混合组 12/40 份回答出现额外的弱相关知识引用；总分 7.675/8 与 7.35/8。配对比较混合 2 胜、14 负、24 平。**AI 辅助评分，未经独立人工验证**；知识引用字段可能暴露检索条件，不是严格盲评，且分数不等于诊断准确率。

评测输出保留原始响应、盲化待评文本、条件映射及汇总评分文件；条件映射仅在评分完成后使用。评分脚本为 `scripts/score-blind-ai-review.py` 与 `scripts/aggregate-blind-ai-scores.py`。该评分由模型完成，未由独立人工复核；只能用来发现引用支持风险，不能作为准确率或因果改进证据。当前离线检索和建议阈值来自合成模板集，真实支付事件分布、独立人工相关性标注和调用价格费率都尚未验证。
