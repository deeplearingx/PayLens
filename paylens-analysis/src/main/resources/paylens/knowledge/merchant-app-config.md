# 商户或应用配置核查

适用情形：支付请求被拒绝、路由异常，或日志提示商户、应用、产品权限或通道账户不可用。

核查建议：核对请求中的商户号、应用标识、支付产品和通道账户是否属于同一业务范围；查看商户与应用的启用状态、产品权限、通道绑定及生效时间。只比对配置标识与状态，不在诊断记录中暴露密钥、证书内容或完整个人信息；必要时请配置管理员复核变更审计。

边界：单条错误信息可能来自标识不匹配、权限或通道侧限制，不能直接归因于某项配置。本文仅提供人工排查建议，不自动启停商户、应用、通道账户或修改配置。
