# 重复回调与幂等核查

适用情形：同一商户订单出现多条通道通知，或平台记录了多次通知处理。

核查建议：比较通知事件编号、通道交易号、商户订单号、脱敏载荷摘要、接收时间和应答；再核对幂等键、状态变更审计及通道实际交易流水。相同事件和交易号通常指向重复投递；不同成功交易号则需要按可能的多笔交易人工核查。

边界：重复通知本身不证明重复扣款，通知处理次数也不等于资金交易次数。本文仅提供人工排查建议，不自动重放通知、退款、合并交易或改写支付状态。
