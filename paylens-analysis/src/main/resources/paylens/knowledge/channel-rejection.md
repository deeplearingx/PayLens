# 通道拒绝支付请求

适用情形：通道响应含拒绝结果或错误码，平台资金状态为 `fail`，或请求结果仍待确认。

核查建议：保留通道名称、响应码、脱敏响应摘要、请求关联号和发生时间；按对应通道接口文档核对错误码含义、商户产品权限、限额和请求参数。若请求超时或结果不确定，先通过可信查单确认是否已产生交易，再评估是否允许后续操作。

边界：错误码含义依通道、产品和接口版本而异；拒绝响应不能替代资金流水核对，超时也不能当作拒绝。本文仅提供人工排查建议，不自动重试支付、退款、修改路由或改写订单状态。
