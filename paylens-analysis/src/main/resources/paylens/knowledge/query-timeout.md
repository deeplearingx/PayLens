# 通道查单超时或状态未知

适用情形：查单请求超时、返回无法识别的状态，或当前证据不能确认通道最终结果。

核查建议：记录查询时间、耗时、超时阶段、请求关联号和通道响应摘要；确认查询使用的商户订单号与通道交易号。等待可用的可信查单结果或通道流水，并记录结果对应的时间点。遇到未知状态时先核对通道状态映射和接口版本。

边界：本次超时或未知响应只说明尚未取得可确认结果，不能据此判断支付成功、失败或未扣款。本文仅提供人工排查建议，不自动重试支付、退款或改写订单状态。
