# 支付金额或币种不一致

适用情形：平台订单、通道交易或对账记录中的金额或币种不同。

核查建议：用同一交易标识逐项比较订单金额、实际扣款金额、币种和精度；确认单位是元还是分，并查看优惠、部分支付、预授权、撤销或分次结算记录。只使用已脱敏的必要字段。把已观察到的差异与可能原因分开记录，交由财务或支付运营人员复核。

边界：金额差异不自动说明少扣、多扣或平台计算错误；未经核实的汇率、舍入和优惠规则不能当作结论。本文仅提供人工核查建议，不自动退款、补扣、冲正或更改订单金额及状态。
