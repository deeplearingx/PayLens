# 平台与通道支付终态冲突

适用情形：同一笔交易的平台资金状态与通道可信结果不同，或观察到不同时间的状态快照。

异常类型编码：`close_paid` 表示平台关单后发现通道成功，`fail_paid` 表示平台判失败后发现通道成功，`cancel_paid` 表示平台取消后发现通道成功。它们描述异常发现时的业务类型，不等同于交易当前状态或人工处置状态。

核查建议：先确认商户订单号、通道交易号和商户号都指向同一交易；比较状态采集时间、时区、来源及通道状态映射；查看回调、查单和人工操作审计。需要时获取新的只读查单结果，并由人工复核资金流水。

边界：旧快照或状态映射差异可能造成表面冲突，单次差异不能证明资金错误。本文仅提供人工排查建议，不自动冲正、退款、重试支付或改写状态。
