# 退款处理中或退款失败

适用情形：退款单仍在处理中、查询结果未知，或通道返回退款失败。退款状态属于退款单生命周期，应与原支付资金状态分开核对。

核查建议：确认退款单号、原通道交易号、退款金额和币种；查看退款请求及应答时间、通道响应码、后续只读查单和资金流水。退款未完成时记录待确认项；失败时先确定失败是否为最终结果，以及原退款请求是否已经在通道侧执行。

边界：退款请求被接受不必然表示款项已退回，单次超时或失败文字也不能证明资金结果。本文仅提供人工排查建议，不自动再次退款、撤销退款或更改退款与支付状态。
