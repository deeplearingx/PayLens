# 支付成功回调缺失

适用情形：通道的可信查单显示支付成功，而平台资金状态仍为 `processing`，或商户没有收到平台通知。

核查建议：用商户订单号和通道交易号确认是同一笔交易；比对通道支付时间、回调投递记录、平台入口访问日志和商户通知应答。检查时确认日志时间范围、时区与保留期限。若缺少任一侧记录，先补齐对应证据再区分未投递、网络失败、验签失败或处理失败。

边界：日志中未找到回调不证明通道没有发送；通道成功也不能单独证明商户业务已处理成功。本文仅提供人工排查建议，不自动补单、重放通知、退款、改写支付状态或修改配置。
