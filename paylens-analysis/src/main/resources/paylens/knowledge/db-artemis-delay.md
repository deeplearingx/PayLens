# 数据库或 Artemis 消息处理延迟

适用情形：状态变化晚于通道响应，或与支付处理有关的持久化、消息发布和消费时间存在明显间隔。

核查建议：围绕同一订单或关联号比较通道响应、应用日志、数据库提交、消息入队、消费和应答时间；确认时区、重试记录、队列深度和消费者健康情况。区分数据库提交延迟、消息积压、消费失败与状态查询缓存旧值；在使用 Artemis 的链路上同时核对发布方与消费者的记录。

边界：时间相关不证明数据库或消息队列是根因；消息存在也不证明业务事务已提交。本文仅提供人工排查建议，不自动重发消息、补单、退款、改写支付状态或调整队列配置。
